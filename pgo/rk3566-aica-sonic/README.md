# RK3566 AICA PGO profile

This directory contains GCC execution profiles for the AICA sources used by
the RK3566/Cortex-A55 Flycast build.

The profiles were collected on an Anbernic RG353M while running Sonic
Adventure 2 with the validated low-end audio mixer. They contain compiler
execution counters only; no ROM, save-state, audio, video or game asset data
is included.

Use the path-independent build wrapper from the repository root:

```sh
JOBS=4 ./tools/build-rk3566-pgo.sh
```

The bundle was generated by GCC 9.4.0 and requires a compatible GCC 9.x
compiler. The wrapper stops instead of silently producing an unprofiled core
when another compiler major version is detected.

Profile source revision: `afbb7b21`. With the validated GCC 9.4.0 environment,
builds from `/mnt/retrorun-host/flycast` and a nested independent checkout
both produced:

```text
b019eea04a29414b7691ced010b5258d1944fe51719e5dd2f87b2d2f0ec2813f
```

The wrapper stages the profiles using the current absolute source path and
builds `flycast_libretro.so` with:

```text
platform=RK3566
PGO_USE=1
PGO_FILTER_FILES=core/hw/aica/.*
```

Do not use this profile bundle for RK3326/Cortex-A35 devices such as the
RG351V. Those devices require a separately trained and validated profile.

Validated fixed-window results on RG353M:

- Sonic Adventure 2: 47.380 to 50.913 FPS (+7.46%);
- Soul Calibur: 58.860 to 58.778 FPS (neutral within measurement noise);
- Dead or Alive 2 combat state: 43.372 to 43.685 FPS (+0.72%).
